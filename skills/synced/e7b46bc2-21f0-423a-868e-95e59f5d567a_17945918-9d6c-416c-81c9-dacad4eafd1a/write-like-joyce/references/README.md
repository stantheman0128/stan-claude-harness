# Joyce 範例文章索引

## 如何使用這個索引

寫文章前，先看下方表格，用「主題標籤」和「文章類型」找到和你要寫的主題最相關的文章。每次至少讀 3 篇：
1. **1 篇主題最相關的**（不管權重多少）
2. **1 篇權重 100% 的**（抓最新語感）
3. **1 篇不同類型的**（確保風格全面）

## 權重說明

權重不是讀取順序，而是風格裁判。所有文章都值得讀，權重只在兩篇風格細節不一致時起作用——以較高權重的為準。

- **100%**（2026年）：最新風格
- **85%**（2025 Q4）：穩定期風格
- **70%**（2025 Q3）：早期風格
